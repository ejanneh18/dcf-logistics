🚀 DCF Logistics - Production Deployment Guide

✅ System Status: Ready for production deployment with full admin functionality, real database integration, and comprehensive analytics.

1Prerequisites

  • Node.js 18+ installed
  • PostgreSQL database (for production)
  • Domain name and hosting provider
  • Email service (SMTP or SendGrid)
  • Stripe account (for payments)
  • Cloudinary account (for file uploads)

2Environment Configuration

Production Environment Variables

Create a .env.production file with the following variables:

# Database (PostgreSQL for production)
DATABASE_URL="postgresql://username:password@host:5432/dcf_logistics"

# NextAuth.js
NEXTAUTH_SECRET="your-super-secure-secret-key-here"
NEXTAUTH_URL="https://yourdomain.com"

# Email Configuration
SMTP_HOST="smtp.youremailprovider.com"
SMTP_PORT="587"
SMTP_USER="noreply@yourdomain.com"
SMTP_PASS="your-email-password"

# App Configuration
APP_URL="https://yourdomain.com"
EMAIL_QUEUE_ENABLED="true"
RATE_LIMIT_ENABLED="true"

3Database Setup

Convert Schema to PostgreSQL

Update prisma/schema.prisma datasource:

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

Deploy Database

# Generate Prisma client
npx prisma generate

# Deploy database schema
npx prisma db push

# Seed with production data
npx prisma db seed

4Build and Deploy

Build Application

# Install dependencies
npm install

# Build for production
npm run build

# Start production server
npm start

Deploy to Vercel (Recommended)

# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
Alternative Platforms:
  • Netlify: Connect GitHub repo, set build command to npm run build
  • Railway: Connect repo and configure environment variables
  • DigitalOcean: Use App Platform with Node.js buildpack
